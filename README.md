# 🌊 Asteroid Bouncers

**Asteroid Bouncers** – a game where you use asteroids to knock out planets of the solar system. 

## 🎮 Gameplay
Each asteroid has its own color, which must match the color of the planet's parts to remove them. Earn points for each knocked-out planet sphere.
